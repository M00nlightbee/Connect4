# Connect4
Python connect 4 game with AI search algorithms

## About this project
Exploring AI&ML algorithm concepts for building an intelligent system to play against human and other agents
- Connect 4 is a two-player game played on a grid consisting of seven columns and six rows.
- Each player takes turns to drop a disc in one of the seven columns. 
- The disc then drops to the lowest empty slot in that column. 
- The disc can be dropped only from one of the columns.
- Each player is associated with a unique colour to distinguish the disc dropped. 
- To win the game the player must align four discs (of the colour assigned to that player) consecutively either horizontally, vertically or diagonally. 
- First player to connect four of their discs in a line (i.e., horizontally or vertically or diagonally) wins the game.
